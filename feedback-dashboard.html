Key Insights Across All Workshops

Insight 01 Everyone wants more hands-on time
▾

The single most consistent theme across all three feedback forms — both designers and engineers — is the desire for more hands-on practice. Respondents loved the theory and demos but consistently wished for more time building things themselves. Multiple people suggested recurring sessions or deep-dive follow-ups.

More hands-on time Recurring sessions Deep-dive follow-ups Own projects
Insight 02 The "how AI works" explanations were a standout moment
▾

Across Workshop 1, the most praised element was the foundational explanation of how LLMs work. Phrases like "autocomplete on steroids" and "demystifying how AI works" come up repeatedly. People felt it changed how they thought about AI — not just how they used it.

LLM architecture Demystifying AI Changed mental model Prompting techniques
Insight 03 Fear of technology was reduced — "it's not that hard"
▾

Several designers specifically mentioned that the workshop removed their fear of non-design tools. Responses like "fear of exploring a non-design tool went away" and "it's really not that hard, don't fear technology" show the workshop succeeded in making AI accessible to a non-technical audience.

Accessibility Fear reduction Empowerment
Insight 04 Engineers gravitated toward context engineering and advanced workflows
▾

In Workshop 2 (engineers), the most impactful concepts were context engineering, the Research → Plan → Implement workflow, and agent skills. Several engineers specifically want to go deeper on MCP servers and building custom skills — they're ready for the next level.

Context engineering MCP servers Agent skills Phased workflow Git worktree
Insight 05 Designers want Figma ↔ Cursor workflow integration
▾

Multiple designers asked about how Figma and Cursor work together. Questions like "where is Figma needed vs. where can it be bypassed?" and requests for a Figma-to-Cursor workflow demo show strong interest in bridging the design-code gap. Plugin creation was the top exciting use case.

Figma plugin creation Design-to-code Workflow integration Prototyping
