📋 The Instructions

The "ID card" for your plugin — tells Figma what it's called and where to find its parts.

✓ name — plugin name
✓ id — unique identifier
✓ main → code.js
✓ ui → ui.html
✓ editorType — where it works
🧠 The Brain
code.js
Can read & modify your Figma file directly.
Cannot access the internet.

What It Can Do With Your Figma File

See current page
Read all layers
Show the UI window
Show notifications
Create frames & shapes
Close the plugin
💬 Sending messages down
"Here's what's in your file"
💬 Sending messages up
"User clicked this button"
😊 The Face
ui.html
The UI you see — buttons, inputs, animations.
Cannot touch your Figma file directly.

Load data from internet

{
  "name": "Design Token Finder",
  "id": "design-token-finder",
  "main": "code.js",          // → Brain
  "ui": "ui.html",            // → Face
  "editorType": ["figma"]
}
// Show the UI
figma.showUI(__html__);

// Listen for messages from the Face
figma.ui.onmessage = (msg) => {
  if (msg.type === 'copy-token') {
    figma.notify(`Copied!`);
  }
};

// Send data to the Face
figma.ui.postMessage({ type: 'update', data: ... });
<script>
  // Listen for messages from the Brain
  onmessage = (event) => {
    const msg = event.data.pluginMessage;
    updateUI(msg);
  };

  // Send messages to the Brain
  function onButtonClick() {
    parent.postMessage({ 
      pluginMessage: { type: 'do-something' } 
    }, '*');
  }
</script>

🍽️ Restaurant Analogy

📋

The Menu

manifest.json

🧠

The Kitchen

code.js — touches the food

😊

The Dining Room

ui.html — what customers see

Waiters (messages) carry orders between the dining room and kitchen.

🔒 Why Separated? Security.

🧠 Brain = Secure Room

Can touch files, but no internet access.

😊 Face = Public Window

Has internet, but can't touch files.

They talk through messages — keeping your files safe!

The Flow

1

Run Plugin

Figma reads manifest.json

2

Brain Wakes Up

code.js can now access your file

3

Face Appears

ui.html shows the interface

4

They Communicate

Messages pass between them
