## Slide 3: Cursor Interface Tour
**Time: 7 mins**

### Main Components

| Component | What It Does | Shortcut |
|-----------|--------------|----------|
| **Editor Panel** | Where code lives (like a smart text editor) | - |
| **File Explorer** | Your project's folder structure | `Cmd/Ctrl + B` |
| **Agent Chat** | Your AI coding partner | `Cmd/Ctrl + L` |
| **Inline Chat** | Quick edits in context | `Cmd/Ctrl + K` |
| **Plan Mode** | Think before building | Toggle in chat |
| **Context Gauge** | AI's "working memory" | Watch the % |

### Key Concepts

**Agent Chat (`Cmd/Ctrl + L`)**
- Your main conversation with AI
- Describe what you want to build
- AI generates code and makes changes

**Plan Mode**
- Switch to "Plan" before building
- AI creates a structured plan first
- Review, then execute

**Context Window**
- The AI's "working memory"
- Watch the percentage gauge
- Keep conversations focused

**New Chat = Fresh Memory**
- Starting a new chat wipes memory
- Be intentional about what context to include
- Use rules files for persistent preferences
