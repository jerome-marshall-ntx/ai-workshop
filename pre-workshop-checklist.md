## Pre-Workshop Tasks

### 1 Week Before
- [ ] **Test Plugin Loading**
  - Open Figma Desktop
  - Load `design-token-finder/manifest.json`
  - Verify plugin appears in menu
  - Test all functionality (search, tabs, copy)

- [ ] **Gather Real Tokens**
  - Collect 10-15 tokens from your design system
  - Include colors, spacing, typography
  - Have them ready to paste during workshop

- [ ] **Practice Space Invaders Demo**
  - Follow `demo-script/space-invaders-demo.md`
  - Time yourself (should be ~20 mins)
  - Note any issues or questions

- [ ] **Test Backup Version**
  - Open `backup-standalone/index.html` in browser
  - Verify it works correctly
  - Test all features

- [ ] **Send Prerequisites Email**
  - Use template from `facilitator-guide.md`
  - Include setup instructions
  - Remind about Figma Desktop requirement

### 1 Day Before
- [ ] **Review All Materials**
  - Read through `workshop-agenda.md`
  - Review `facilitator-guide.md`
  - Check `demo-script/space-invaders-demo.md`

- [ ] **Test Setup on Workshop Machine**
  - Verify Cursor is installed and working
  - Verify Figma Desktop is installed
  - Test plugin loading one more time

- [ ] **Prepare Sample Tokens**
  - Copy real tokens to clipboard or file
  - Have design system docs open
  - Prepare 3-5 examples of each category

- [ ] **Set Up Presentation**
  - Test projector/screen sharing
  - Have slides ready to display
  - Prepare backup video if needed

### Day Of Workshop
- [ ] **Arrive Early (15 mins)**
  - Set up presentation equipment
  - Test plugin loading one final time
  - Have backup standalone ready
  - Open design system documentation

- [ ] **Final Verification**
  - Cursor opens correctly
  - Figma Desktop works
  - Plugin loads successfully
  - Sample tokens ready to paste

- [ ] **Prepare for Questions**
  - Review troubleshooting guide
  - Know backup options
  - Have resources list ready

## Success Criteria

Workshop is successful if:
- [ ] Attendees can navigate Cursor confidently
- [ ] Everyone builds a working plugin (or understands how)
- [ ] Attendees feel empowered to try building tools
- [ ] Questions are answered clearly
- [ ] Energy stays high throughout

## Quick Reference During Workshop

**If plugin won't load:**
→ Use `backup-standalone/index.html`

**If running behind:**
→ Skip detailed explanations, focus on workflow

**If attendee struggling:**
→ Pair them up, provide completed code reference

**If demo fails:**
→ Use pre-recorded video or screenshots
