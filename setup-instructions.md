# Setup Instructions for Workshop

## For Attendees

### Step 1: Install Cursor IDE

1. Go to [cursor.com/download](https://cursor.com/download)
2. Download for your operating system (Mac/Windows/Linux)
3. Install the application
4. Open Cursor and sign in (create account if needed)

**Verification:** You should see the Cursor welcome screen with an empty editor.

---

### Step 2: Install Figma Desktop

1. Go to [figma.com/downloads](https://www.figma.com/downloads/)
2. Download Figma Desktop for your OS
3. Install and open Figma Desktop
4. Sign in with your Figma account (create one if needed)

**Important:** You need Figma Desktop, not the web version. The web version doesn't support plugin development.

**Verification:** You should see the Figma Desktop app (not browser).

---

### Step 3: Prepare Your Design System Tokens

**Option A: From Documentation**
- Open your design system documentation
- Have a few token values ready:
  - 3-5 color values (HEX codes)
  - 3-5 spacing values (e.g., 4px, 8px, 16px)
  - 2-3 typography values (font sizes)

**Option B: Use Sample Tokens**
- We'll provide sample tokens during the workshop
- You can customize them later

---

### Step 4: Test Your Setup

**Test Cursor:**
1. Open Cursor
2. Create a new folder called "test"
3. Open it in Cursor
4. Press `Cmd/Ctrl + L` - you should see the chat panel

**Test Figma:**
1. Open Figma Desktop
2. Create a new file
3. Go to `Plugins > Development` - menu should appear

---

## Troubleshooting

### Cursor Won't Open
- Check system requirements
- Try restarting your computer
- Re-download installer

### Figma Desktop Won't Install
- Ensure you have admin permissions
- Check system requirements
- Try downloading again

### Can't Sign In
- Check internet connection
- Try resetting password
- Contact support if needed
