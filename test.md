Hi team,

We're hosting a half-day **Cursor + AI Workshop** designed specifically for engineers. The workshop runs for about 3 hours, split into two sessions with a short break in between.

---

### Session 1 – Foundations of AI for Engineers *(1.5 hrs)*

Even if you already use AI tools daily, understanding the "why" behind these systems helps you get a lot more out of them. We'll walk through:

- How AI has evolved over the years
- What LLMs are good at, and where they still fall short
- How LLMs work behind the scenes
- Prompting techniques that actually improve output quality
- Real-world examples of AI in engineering workflows

---

### Session 2 – Cursor Advanced *(1.5 hrs)*

This session starts with a quick beginner-friendly intro to Cursor, then dives into the advanced features and workflows that make a real difference in day-to-day work. This will be a hands-on session covering:

- Agent workflows and Mode
- Custom commands, rules, skills and subagents
- Context window management
- MCP servers
- Git worktrees and Test-driven development
- Best practices

---

### Prerequisites

Please make sure you have the following installed before the workshop:

- Cursor IDE
- Git
- Node.js

---

**Who is this for?**
All engineers. The full half-day is designed as a single experience, so plan to attend both sessions.

Looking forward to seeing you there!
